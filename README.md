# 🌐 WireGuard Auto-Deploy

Скрипт на Python для автоматизации развертывания и управления конфигурациями клиентов WireGuard VPN. Инструмент упрощает выдачу доступов новым пользователям и стандартизирует процесс настройки.

### 🛠 Функционал
* Автоматическая генерация клиентских конфигурационных файлов (`.conf`).
* Маршрутизация и распределение внутренних IP-адресов.
* Удобный CLI-интерфейс на базе `argparse` для быстрого добавления новых пиров.

### 💻 Использование
Для создания конфигурации нового пользователя выполните команду:
```bash
python wg_deploy.py --add client1 --ip 10.8.0.2 --endpoint 203.0.113.1
